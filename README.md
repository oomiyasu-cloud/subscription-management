# 定期購入管理

日用品の購入履歴を端末内に保存し、容量違いの商品を単価で比較するスマホ優先のPWAです。

## できること

- 商品名、容量、価格、購入日、購入場所を記録
- 購入数、複数パック、パック数量を含めて合計量と単価を計算
- 税込・税抜入力に対応
- g/ml/cm/m/個/枚の入力に対応
- 過去の中央値と比べて「買い」「普通」「高め」を表示
- 保存前にお買い得判定を確認し、購入する場合だけ保存
- 購入間隔から次回購入目安日を表示
- iPhoneのホーム画面に追加してアプリのように起動
- オフライン時も保存済みのアプリ本体を表示
- 「保存」画面からJSONバックアップを書き出し、必要なときに読み込み
- Supabaseを設定するとログインしてクラウド保存

## 使い方

```bash
npm run serve
```

ブラウザで `http://localhost:5173/` を開きます。

## スマートフォンで使う

Macとスマートフォンを同じWi-Fiにつなぎ、Macでサーバーを起動します。

```bash
npm run serve
```

スマートフォンのブラウザで `http://<MacのIPアドレス>:5173/` を開きます。

MacのIPアドレスは、例として `192.168.0.245` のような形式です。現在のMacでは、同じWi-Fi上のスマートフォンから `http://192.168.0.245:5173/` で開ける可能性が高いです。

スマートフォンで開いたあと、ブラウザの共有メニューからホーム画面に追加すると、アプリのように起動できます。通常は端末内に保存されるため、クラウド設定なしでも使えます。

## バックアップ

「保存」画面の「バックアップを書き出す」から、現在のデータをJSONファイルとして保存できます。機種変更や念のための控えを作りたいときは、このファイルを保管してください。

「バックアップを読み込む」から保存済みファイルを選ぶと、現在の端末内データをバックアップ内容に置き換えます。

## クラウド保存を使う

Supabaseでプロジェクトを作成し、Authenticationのメール/パスワードログインを有効にします。

1. SupabaseのSQL Editorで `docs/supabase-schema.sql` の内容を実行します。
2. SupabaseのProject URLとanon public keyを `src/cloudConfig.js` に設定します。

```js
export const cloudConfig = {
  supabaseUrl: "https://xxxxxxxx.supabase.co",
  supabaseAnonKey: "public-anon-key",
};
```

3. アプリの「同期」画面で新規登録またはログインします。

設定前や未ログイン時は、これまで通り端末内に保存されます。ログイン後は購入・編集・削除のたびにクラウドへ保存され、別の端末で同じアカウントにログインすると同じデータを読み込めます。
